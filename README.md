# 鲜仓 · 生鲜库存与效期管理

可运行的本地项目：Python 标准库 + SQLite + 原生 JavaScript。无第三方依赖、无云服务、无前端构建步骤。

## 启动

需要 Python 3.10 或以上版本。Windows 双击 `start.bat`；或在项目目录执行：

```powershell
python app.py --demo --open
```

浏览器地址：<http://127.0.0.1:8765>。停止服务：在运行窗口按 `Ctrl+C`。

首次启动写入 8 种演示商品及演示批次，所有初始业务数据均为示例，不代表任何公司的实际经营数据。重复启动保留已有数据，不重置。默认数据库为 `data/inventory.db`。

从空白库存开始，使用独立数据库：

```powershell
python app.py --db data/my-warehouse.db --port 8766 --open
```

端口被占用时改用 `--port 8766`。

## 已实现

| 模块 | 能做什么 |
| --- | --- |
| 运营概览 | 库存成本金额、在库批次、效期风险、今日出库与报损、近七日单据趋势 |
| 商品资料 | 新增/编辑名称、分类、安全库存和临期阈值；商品编码与单位不可改 |
| 库存台账 | 商品、批次、库位查询，分类/状态筛选；支持同批次追加到货 |
| 入库 | 记录供应商、生产日期、到期日、数量、成本和库位 |
| 出库 | FEFO 先到期先出，跨批次自动分配，库存不足整笔回滚 |
| 效期预警 | 按商品阈值显示临期、过期批次；列出低库存和补货缺口 |
| 报损 | 指定批次扣减，必须填写原因，自动记录成本金额 |
| 盘点 | 输入实盘数量，记录账面量/差异并调整库存；版本冲突阻止覆盖 |
| 出入库流水 | 按类型、商品、批次、单号、操作人搜索，保留每次操作后余额 |
| 导出与备份 | Excel 可直接打开的 UTF-8 BOM CSV；SQLite 一致性快照备份 |

## 10 分钟演示流程

1. 打开演示工作区，查看过期批次、临期批次及补货建议。
2. 在“商品资料”新建 `TEST-001 / 测试西兰花 / 蔬菜 / kg`，安全库存设 5，临期预警设 3。
3. 新建两笔入库：批次 `TEST-A` 入库 3 kg，明天到期；批次 `TEST-B` 入库 8 kg，7 天后到期。生产日期用今天。
4. 申请出库 5 kg，系统先扣 TEST-A 的 3 kg，再扣 TEST-B 的 2 kg。
5. 再申请出库 20 kg，系统提示不足，验证批次数量不变。
6. 对 TEST-B 盘点：账面 6 kg，实盘填 5.5 kg，原因填“称重发现 0.5 kg 差异”；查看盘点和流水记录。
7. 对演示过期批次登记报损，观察预警和库存成本变化。
8. 导出库存、流水、盘点 CSV，下载数据库备份；重启后确认数据仍在。

## 数据与业务规则

- 数量以千分之一单位存为整数，输入最多三位小数，避免浮点扣库存误差。
- 单位成本以分存储，最多两位小数。库存成本金额 = 数量 × 单位采购成本；金额仅作成本统计，不计税费。
- 日期按 UTC+08:00 计算。到期当天可出库，之后视为过期；按到期日、生产日、批次 ID 顺序分配。
- 临期：`0 <= 剩余天数 <= 商品预警天数`；清零批次不纳入预警。
- 可用库存排除过期批次；低库存为可用量小于安全库存。补货建议仅计算缺口，不计在途、销售预测和起订量。
- 库存变动使用 SQLite `BEGIN IMMEDIATE` 事务；并发请求串行修改，避免超卖。
- 盘点使用批次版本号。入库、出库、报损、盘点均更新版本，旧页面不能覆盖新库存。
- 请求 ID 用于幂等，同一请求重试不重复扣库存；同 ID 不同内容返回冲突。
- 多个批次的出库流水共用请求 ID；图表按请求 ID 计业务笔数。CSV 导出全部记录，不受网页筛选影响。
- 表格展示使用 HTML 转义；CSV 文本字段防公式注入。服务仅绑定 `127.0.0.1`，检查 Host、Origin 和写请求令牌。

## API

所有写入使用 JSON，带 `request_id`；库存操作另需 `operator`。先请求 `GET /api/state`，将返回的 `token` 放入后续写请求的 `X-App-Token` 请求头。

| 方法与路径 | 用途 |
| --- | --- |
| GET /api/state | 商品、批次、流水、盘点、指标和会话令牌 |
| POST /api/products | 新建商品；带 id 时编辑商品 |
| POST /api/inbound | 入库：product_id、code、location、supplier、produced_on、expires_on、qty、cost |
| POST /api/outbound | 出库：product_id、qty、reference |
| POST /api/damage | 报损：batch_id、qty、note |
| POST /api/count | 盘点：batch_id、version、actual、note |
| GET /api/export?kind=stock | 库存 CSV；kind 也可为 movements、counts |
| GET /api/backup | 下载一致性 SQLite 数据库快照 |

## 备份恢复

先停止服务，将下载的 `.db` 文件放入 `data`，使用一个新的文件名，然后执行：

```powershell
python app.py --db data/restored.db --open
```
